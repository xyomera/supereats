# SuperEats

> This is my first Fabric mod.

A Minecraft mod that adds powerful food items with extraordinary effects.

## Requirements

| Dependency | Version    |
|------------|------------|
| Minecraft | 26.2       |
| Fabric Loader | >= 0.19.3  |
| Fabric API | >= 0.158.0 |
| Java | >= 25      |

## Installation

1. Install <Fabric Loader> for Minecraft 26.2.
2. Download <Fabric API> and place it in your `mods` folder.
3. Download the latest SuperEats release from the Releases page.
4. Place the `.jar` file in your `mods` folder.
5. Launch the game.

## Building from Source

```bash
git clone https://github.com/xyomera/supereats.git
cd supereats
./gradlew build
```
